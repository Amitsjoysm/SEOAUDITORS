After running ./3-build-frontend.sh on your local machine:

1. The script will create: frontend-source/build/

2. Upload ALL contents of frontend-source/build/ to your server at:
   /www/wwwroot/MarketAutoMailer.mj.publicvm.com/

3. Your server root should have:
   /www/wwwroot/MarketAutoMailer.mj.publicvm.com/
   ├── index.html
   ├── static/
   │   ├── css/
   │   ├── js/
   │   └── media/
   ├── manifest.json
   └── favicon.ico

4. Then run ./4-start-services.sh to complete deployment
